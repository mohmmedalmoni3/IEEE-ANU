## PostgreSQL

The backend now uses PostgreSQL through `DATABASE_URL`.

For local development you can run:

```bash
docker compose up -d
npm run db:seed --workspace backend
npm run dev
```

If you have old SQLite data in `backend/data/ieee-anu.sqlite`, migrate it after PostgreSQL is running:

```bash
npm run db:migrate:sqlite --workspace backend
```
